# Global-E-Commerce-Revenue-and-Sales-Analysis
NoE-Commerce Sales and Revenue Analysis

Project Overview

This project analyzes global e-commerce sales data using Excel, MySQL, and Power BI to understand sales performance, revenue trends, and business insights.

Tools Used

- Microsoft Excel
- MySQL
- Power BI

Project Steps

1. Data cleaning and preparation using Excel.
2. Data analysis using Pivot Tables and Charts.
3. Data storage and querying using MySQL.
4. Data visualization using Power BI.
5. Created an interactive dashboard to analyze business performance.

Key Analysis

- Total Revenue
- Total Profit
- Total Quantity Sold
- Country-wise Sales
- Category-wise Sales
- Monthly Sales Trends
